Les Mugiwara

Les Mugiwara, également connus sous le nom de Chapeaux de paille, sont l'équipage principal dans la série animée et manga "One Piece". Ils sont dirigés par Monkey D. Luffy, un jeune pirate dont le rêve est de devenir le Roi des Pirates en trouvant le légendaire trésor connu sous le nom de One Piece.

Membres de l'équipage

  • Monkey D. Luffy - Capitaine
  • Roronoa Zoro - Épéiste
  • Nami - Navigatrice
  • Usopp - Tireur d'élite
  • Sanji - Cuisinier
  • Tony Tony Chopper - Médecin
  • Nico Robin - Archéologue
  • Franky - Charpentier naval
  • Brook - Musicien
  • Jinbe - Timonier
